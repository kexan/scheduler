# 📅 Планировщик миграций компаний

Веб-приложение на Rust для управления записями на миграцию компаний. Позволяет администраторам создавать временные слоты, а пользователям - записываться на них.

## 🚀 Возможности

### Для администраторов:
- ✅ Создание временных слотов (дата, время начала и окончания)
- ✅ Редактирование существующих слотов
- ✅ Удаление слотов
- ✅ Просмотр всех слотов и их статусов
- ✅ Просмотр информации о записавшихся компаниях

### Для пользователей:
- ✅ Просмотр доступных слотов
- ✅ Запись на свободный слот
- ✅ Заполнение формы с данными компании:
  - Название компании
  - Почта администратора компании в облаке
  - ID компании (можно получить через Ctrl+Alt+Q)
  - Почта для отправки ссылки скачивания
- ✅ Визуальное отображение занятых слотов

## 🛠️ Технологический стек

- **Backend**: Rust + Tokio + Warp
- **Frontend**: HTML5 + CSS3 + JavaScript (Bootstrap 5)
- **Сериализация**: Serde
- **Время**: Chrono
- **UUID**: uuid crate с поддержкой serde

## 📋 Требования

- Rust 1.70+ 
- Современный веб-браузер

## 🚀 Запуск

1. **Клонируйте и перейдите в директорию проекта:**
   ```bash
   cd migration-scheduler
   ```

2. **Соберите проект:**
   ```bash
   cargo build --release
   ```

3. **Запустите сервер:**
   ```bash
   cargo run --release
   ```

4. **Откройте браузер:**
   Перейдите по адресу http://localhost:3030

## 📚 API Эндпоинты

### Получить все слоты
```
GET /api/slots
```

### Создать новый слот
```
POST /api/slots
Content-Type: application/json

{
  "date": "2024-12-25",
  "start_time": "10:00",
  "end_time": "12:00"
}
```

### Записаться на слот
```
POST /api/slots/{slot_id}/book
Content-Type: application/json

{
  "company_name": "Название компании",
  "admin_email": "admin@company.com",
  "company_id": "12345",
  "download_email": "download@company.com"
}
```

### Обновить слот
```
PUT /api/slots/{slot_id}
Content-Type: application/json

{
  "date": "2024-12-25",
  "start_time": "10:00",
  "end_time": "12:00"
}
```

### Удалить слот
```
DELETE /api/slots/{slot_id}
```

## 🎮 Использование

### Для администраторов:
1. Откройте http://localhost:3030
2. Нажмите "🔧 Режим администратора"
3. Нажмите "➕ Создать новый слот"
4. Заполните форму (дата, время начала и окончания)
5. Слот появится в общем списке

### Для пользователей:
1. Откройте http://localhost:3030
2. Найдите подходящий свободный слот (зеленый)
3. Нажмите "Записаться"
4. Заполните форму с данными компании
5. Подтвердите запись

### Получение ID компании:
1. Зайдите в свою компанию в облаке
2. Нажмите Ctrl+Alt+Q
3. Скопируйте появившийся ID

## 🔧 Конфигурация

Приложение работает на порту **3030** по умолчанию. Изменить порт можно в файле `src/main.rs`:

```rust
warp::serve(routes)
    .run(([127, 0, 0, 1], 3030))  // Измените порт здесь
    .await;
```

## 🐛 Особенности

- Все данные хранятся в памяти приложения
- При перезапуске сервера все слоты и записи удаляются
- Приложение поддерживает работу с несколькими пользователями одновременно
- CORS включен для работы с веб-интерфейсом
